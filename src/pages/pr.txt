MonthlyAnalysis.jsx — boutons de navigation inversés
Dans le JSX, tu as mis goToNextMonth sur le bouton gauche (ChevronLeft) et goToPrevMonth sur le bouton droit (ChevronRight) :
jsx// ❌ INVERSÉ
<button onClick={goToNextMonth} ...>  {/* bouton gauche ← */}
  <ChevronLeft size={18} />
</button>

...

<button onClick={goToPrevMonth} disabled={isCurrentMonth} ...>  {/* bouton droit → */}
  <ChevronRight size={18} />
</button>
Remplace par :
jsx// ✅ CORRECT
<button onClick={goToPrevMonth} ...>
  <ChevronLeft size={18} />
</button>

...

<button onClick={goToNextMonth} disabled={isCurrentMonth} ...>
  <ChevronRight size={18} />
</button>
